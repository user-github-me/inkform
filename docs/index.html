01 / Learn the writer

The hand comes
before the page.

A reusable profile begins with evidence. Each new document uses forms that have already been learned and reviewed.

  1. 01

    Bring your samples

    Start with photos, scans, or PDF pages of your writing. Inkform preserves the originals and prepares local copies.

    Your own handwriting →
  2. 02

    Learn & review

    An agent identifies forms, fits vector geometry, and checks it against the source. Reviewed variants become your private profile.

    A reviewed profile →
  3. 03

    Calibrate the page

    Compare a specimen with your samples. Refine the shapes and ink, then check a print at Actual Size / 100%.

    A comparison at print size →
  4. 04

    Write something new

    Check the exact text and symbols against your profile, then export a PDF. Keep learning as you add more samples.

    A profile you can reuse ↗

↳ Training is local exemplar learning: fitted forms, reviewed variants, and supported measurements. A folder import alone is not a learned alphabet; no neural network is trained.

An honest first release

Useful today.
Room to get closer.

The engine checks the file. People and agents still judge resemblance, spacing, and the page in their hands.

What you can build with

  • Reusable local profiles. Source references, review actors, variants, and immutable versions.
  • Two vector representations. Reviewed centerlines and smooth outlines, with a saved writer preference.
  • Exact content and explicit gaps. Missing forms produce a request for evidence. Text and mathematical roles remain distinct.
  • Repeatable, inspected output. Saved seeds, unchanged content sidecars, PDF object checks, and rendered previews.

Where the work continues

  • Review remains part of training. Sample segmentation and fitted geometry need an agent or person to inspect them.
  • Spacing needs richer evidence. Connected cursive and spacing learned from whole words are still developing.
  • Outlines have physical limits. New sizes, script forms, or stroke weights need compatible reviewed geometry.
  • The print is the proof. File validity cannot establish a handwriting match. Compare actual-size samples and printed pages.
Which mathematical structures are supported?+

Symbols, numbers, rows, relations, function calls, fractions, square roots, superscripts, subscripts, and limits with explicit left, right, or two-sided direction. Support still depends on your profile's reviewed forms and representation. The renderer preserves supplied content; solving and answer verification happen before rendering.
